# Avatar-Item-Collection

Avatar item packages used by [XeCLI](https://github.com/xecli/xecli)'s `rgh avatar` commands.

XeCLI downloads items from this repository on demand, so most people never need to clone it. To use a local copy instead, point XeCLI at it:

```powershell
rgh avatar config --path <folder>
```

See the [Avatar Item Collection](https://github.com/xecli/xecli/wiki/Avatar-Item-Collection) page in the XeCLI wiki for details.
